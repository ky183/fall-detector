# CNN 二级仲裁 v2 交接文档（v0.4，2026-09-11）

> 写给算法组：本文说明对 CNN 二级仲裁（commit `e23f5d5`，下称 v1）的审阅结论、
> 本轮全部改动、理由与验证结果。改动仅涉及**训练侧与一个固件开关**，
> 你的板端实现（cnn_detector.cpp / cnn_detector.h / host_replay）一行未动。
> 复核指引见 §8，全部结论可用仓库内工具一键复现。

## 0. 一句话摘要

v1 的板端移植质量过硬（双语言回放 0 不一致），但训练侧有三处方法论问题
（窗口泄漏 / trial 级标签 / 无域增广），导致其指标虚高、且不可直接部署。
本轮重写训练脚本（v2）并以**影子模式**上板：RF 仍独自主判，CNN 只记录
不生效，等佩戴测试攒够对照数据后再决定是否授权。

## 1. 对 v1 的审阅结论（已当面/文档反馈过，此处留档）

**保留不动的部分**（这些做得很好）：
- 腰腕 12 通道输入设计与"二级仲裁只看腕端增量信息"的定位
- 归一化换算链（LSB 往返）与文件头文档 —— 实测量化过错法代价，可信
- 全部工作缓冲 static 化（避开 18KB 栈溢出）
- host_replay 三层验收 + check_consistency 静态自检 —— 本轮全部复用

**发现的问题**（均为训练侧，板端无 bug）：
1. 随机窗口划分：50% 重叠的相邻窗口横跨训练/测试两侧 -> 指标虚高
2. trial 级标签：摔前站立、摔后躺卧的窗口也被标为"跌倒" -> 错误语义
3. 无部署域增广：训练数据腕端从不缺失、轴向固定，与实机（丢包 + 佩戴
   朝向不可控）存在两个未对齐的域差

## 2. 改动清单与理由

### 2.1 firmware/waist_firmware/config.h —— 影子模式（1 行）

`CNN_ROLE_RESCUE` 1 -> 0。

- **影响**：CNN 照常计算并记录（decision 日志的 `cnn p=` 行不变），
  但不再能把 RF 未判跌倒的事件补判为报警。行为回退到纯 RF（= 已验证的 v2 主判决）。
- **理由**：v2 重训后的真实灵敏度约 70~78%（RF 为 96%），在"RF 漏掉的
  子集"上的表现未测过，不应有改变判决的权力。
- **开启条件**：佩戴测试攒出"RF 对/错 × CNN p 高/低"对照表且分布达标后。

### 2.2 algo/cnn/cnn_train.py —— 重写为 v2

| 修复 | 实现 | 理由 |
|---|---|---|
| 按受试者划分 | 每 5 人留出 1 人（本次 1/5/14），jitter 副本只进训练侧 | 消除窗口泄漏，测试集全是训练没见过的人 |
| 峰值锚定标签 | 正样本=腰端 SVM 峰值居中 2s 窗（与板端 cnn_detector_prob 取窗同构）；摔前(-6,-4s)/摔后(+4,+6s)补负样本 | 标签语义改为"窗口内正在跌倒"，且训练/部署取窗方式一致 |
| 腕端缺失增广 | 25% 整窗置 0 + 25% 随机 30% 拍置 0 | 板端 cov<1 的窗口里有 0 值，原属域外输入 |
| 随机旋转增广 | 腰/腕各自独立随机 SO(3)，同端 acc/gyr 同一旋转矩阵（保手性） | 腕端 PCB 佩戴朝向不可控 + 数据集轴向无从核对，迫使模型学朝向无关特征 |
| ablation | 旋转开/关各训一版对比，导出旋转版 | 项目纪律：不让性能无谓变差，用数据取舍 |

归一化常量与导出格式与 v1 逐字一致，**板端无需任何改动**。
新增 `--smoke`（合成数据验流程）、`--no-rot`、`--epochs` 参数。

### 2.3 firmware/waist_firmware/cnn_weights.h —— 重新导出

v2 旋转增广版权重（6210 float，规模不变）。由 2.2 的脚本自动生成。

### 2.4 新增 algo/cnn/inspect_data.py —— 数据体检工具

训练前的数据可信度检查（标度 / SMOTE 痕迹 / 腕陀螺来源 / 零填充），
答辩复现用。本次对 FallAllD 处理版 pkl 的体检结论见 §3。

## 3. 数据体检结论（FallAllD_40SamplesPerSec_ActivityIdsFiltered.pkl）

来源核实为 Kaggle "Derived FallAllD Dataset"（CC0）。四个关键结论：

1. **标度精确成立**：腰端静止段 |acc| 中位数换算后 = 1.00g（50 分位），
   证实 4096 LSB/g 假设；与板端 ±8g/±500dps 换算链完全对齐
2. **腕端陀螺是真实独立通道**（与腰部相关系数仅 0.19，非复制非填充）
3. **未发现 SMOTE 合成样本**（索引连续、无重复键）——Kaggle 数据卡片
   声明的 SMOTE 只在上传者自己的 notebook 里，未写入 pkl
4. trial 统一 800 点（20s）为截断而非填充（尾部零值占比 0%）

结论：该 pkl 可直接用于训练；原始版 FallAllD.pkl（462MB）留作后备。

## 4. v2 训练结果（真实、无泄漏）

数据：3875 窗（正 370 / 负 3505），留出受试者 1/5/14，seed=42，50 epochs。
完整报告见 `algo/out/cnn_train_report.txt`。

| 测试条件 | A 旋转增广（已导出） | B 无旋转（对照） |
|---|---|---|
| 原始轴向 | sens 67.5% / spec 99.8% | sens 70.0% / spec 98.8% |
| **随机旋转（模拟腕端乱戴）** | **sens 77.5% / spec 98.7%** | sens 92.5% / **spec 77.7%（崩）** |
| 旋转 + 30% 丢包 | sens 77.5% / spec 97.8% | spec 74.1%（崩） |

- B 的 sens 升高是"整体倾向报跌倒"的假象（伴随 spec 崩盘证实）；
  其判据依赖轴向信息，轴向一变行为不可控
- **A 在全部条件下 spec ≥ 97.8%，是任意佩戴朝向下唯一可信的版本**
- 真实灵敏度 70~78% vs RF 主判决 96% —— 影子模式的直接依据
